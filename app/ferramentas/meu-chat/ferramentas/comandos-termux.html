🔍 Diagnóstico — O que está instalado
Ver tudo instalado e salvar em Downloads
Gera o arquivo termux-instalados.txt na pasta Downloads com tudo: Termux, NPM global, projeto SK e Python.
echo "=== TERMUX GLOBAL ===" > ~/storage/downloads/termux-instalados.txt && pkg list-installed >> ~/storage/downloads/termux-instalados.txt && echo "" >> ~/storage/downloads/termux-instalados.txt && echo "=== NPM GLOBAL ===" >> ~/storage/downloads/termux-instalados.txt && npm list -g --depth=0 2>/dev/null >> ~/storage/downloads/termux-instalados.txt && echo "" >> ~/storage/downloads/termux-instalados.txt && echo "=== PROJETO SK-Juridico ===" >> ~/storage/downloads/termux-instalados.txt && cd ~/minisk/SK-Juridico-1.7.6 && npm list --depth=0 2>/dev/null >> ~/storage/downloads/termux-instalados.txt && echo "" >> ~/storage/downloads/termux-instalados.txt && echo "=== PYTHON PACOTES ===" >> ~/storage/downloads/termux-instalados.txt && pip list 2>/dev/null >> ~/storage/downloads/termux-instalados.txt && echo "✅ Arquivo salvo em Downloads!"
Ver só o que está no projeto SK
Lista os pacotes instalados dentro da pasta do projeto SK Jurídico.
cd ~/minisk/SK-Juridico-1.7.6 && npm list --depth=0
Ver pacotes NPM globais
Lista tudo que foi instalado globalmente no Node/NPM do Termux.
npm list -g --depth=0
Ver pacotes Python instalados
Lista tudo que foi instalado via pip no Termux.
pip list
Ver versões instaladas (Node, Python, Git)
Mostra a versão de cada ferramenta principal.
echo "Node: $(node -v)" && echo "NPM: $(npm -v)" && echo "Python: $(python --version)" && echo "Git: $(git --version)" && echo "PM2: $(pm2 -v 2>/dev/null || echo 'não instalado')"
⚙️ Instalação — Pacotes essenciais
Instalar dependências do projeto SK
Entra na pasta do projeto e instala tudo que está no package.json.
cd ~/minisk/SK-Juridico-1.7.6 && npm install
Instalar pacotes essenciais do servidor
Instala express, dotenv, cors, jsonwebtoken e tsx dentro do projeto.
cd ~/minisk/SK-Juridico-1.7.6 && npm install express dotenv cors jsonwebtoken tsx
Instalar banco de dados local (SQLite)
Instala o better-sqlite3 para usar banco local sem precisar do Neon/nuvem.
cd ~/minisk/SK-Juridico-1.7.6 && npm install better-sqlite3
Instalar PM2 (mantém servidor rodando)
Instala o PM2 globalmente para o servidor não cair quando fechar o terminal.
npm install -g pm2
🚀 Servidor — Iniciar e parar
Iniciar o servidor SK Jurídico
Entra na pasta e tenta iniciar o servidor do projeto.
cd ~/minisk/SK-Juridico-1.7.6 && npm run dev
Ver o que está rodando nas portas
Mostra quais processos estão ocupando portas no momento.
ss -tlnp | grep -E '3000|5000|8080|4000'
Matar processo em porta específica
Para o processo que está usando a porta 3000 (troque o número se precisar).
fuser -k 3000/tcp
📁 Arquivos — Navegar e organizar
Ver pastas do Mini SK
Lista o que existe dentro da pasta principal do Mini SK.
ls -la ~/minisk/
Ver tamanho das pastas
Mostra quanto espaço cada pasta do Mini SK está ocupando.
du -sh ~/minisk/*/
Fazer backup do projeto SK
Copia o projeto inteiro para a pasta Downloads com data no nome.
cp -r ~/minisk/SK-Juridico-1.7.6 ~/storage/downloads/SK-backup-$(date +%Y%m%d-%H%M)
📱 Saúde do celular
Ver memória RAM disponível
Mostra quanto de memória está livre e em uso.
free -h
Ver espaço em disco
Mostra quanto espaço está livre no armazenamento.
df -h ~/storage/

Mostra RAM, disco e processos rodando de uma vez só.

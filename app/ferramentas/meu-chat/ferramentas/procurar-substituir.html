❓ Como usar
✅ Para trocar a chave do Gemini:
1. Cole o código na caixa grande
2. Clique no atalho "🔑 Chave Gemini"
3. No campo "Substituir por" coloque sua nova chave AQ.Ab...
4. Clique "Substituir tudo"
5. Copie o resultado
🔄 Para trocar o modelo:
1. Cole o código
2. Clique no atalho do modelo que quer trocar
3. Clique "Substituir tudo"
4. Copie o resultado
⚠️ Cuidado com maiúsculas:
Por padrão não diferencia maiúsculas. Se precisar diferenciar, marque a caixinha.
⚠️ Projetos da Replit (index/boot):
Funciona da mesma forma! Cole o conteúdo do arquivo, faça a substituição e copie de volta. Funciona para qualquer arquivo de texto.
🔴 Não funciona para:
Arquivos binários (imagens, APK compilado). Só funciona em arquivos de texto.

🎙 Transcrever Áudio

Áudios do WhatsApp (e outros) viram texto literal, palavra por palavra, com o tempo de cada trecho. Junto vai a ficha do arquivo original (nome, tamanho, duração, data e a impressão digital SHA-256), para mostrar que o áudio não foi mudado.

1. Escolha os áudios

No WhatsApp: abra a conversa → segure o áudio → ⋮ → Compartilhar → salvar em "Arquivos" (ou: ⋮ da conversa → Mais → Exportar conversa → com mídia). Os áudios têm o final .opus.

2. Quem vai transcrever

A chave fica só neste aparelho. Groq grátis: console.groq.com → API Keys (começa com gsk_).

4. O documento

Confira ouvindo cada áudio e corrija no texto se precisar (a IA pode errar nome, número ou palavra difícil). Depois:

⚖️ Cuidados para usar como prova
  • Guarde o áudio original sem mexer. A impressão digital (SHA-256) na ficha permite provar que é o mesmo arquivo: se mudar um único segundo, ela muda toda.
  • A transcrição é automática e tem que ser conferida ouvindo. O documento diz isso.
  • Se a outra parte contestar, os caminhos usuais são juntar o próprio áudio, a ata notarial ou a perícia. A transcrição ajuda o juiz a ler; não substitui o arquivo.

🔑 O que é a "chave de API"?

A chave é como uma senha especial que você coloca nos seus projetos (Meu Chat, Laboratório, etc.) para eles conseguirem usar a IA. Sem ela, o projeto não consegue se conectar.

🔒 NUNCA mostre sua chave para ninguém! Quem tiver ela pode gastar seus créditos.
📋 Como pegar a chave
1
Entre na plataforma
Já logado, vá para o painel principal
Abrir Monica API →
2
Procure "API Keys"
No menu esquerdo, clique em "API Keys" (Chaves de API)
📍 Menu esquerdo → API Keys
3
Clique em "Create New Key"
Dê um nome para lembrar (ex: "Meu Chat") e confirme
✏️ Nome: MeuChat → Create Key
4
COPIE a chave AGORA!
Ela aparece só uma vez. Copie e salve num lugar seguro (ex: bloco de notas no celular).
🔑 sk-monica-xxxxxxxxxxxxxxxxxxxxxxxx
5
Cole nos seus projetos
No Meu Chat, Laboratório, etc. — onde pede "Chave de API", cole ela.
⚙️ Configurações → Chave de API → Cole aqui

❓ Perguntas frequentes
🤔 Tenho assinatura Pro da Monica. Posso usar a API de graça?
NÃO. A assinatura Pro e a API são sistemas separados. Precisa colocar crédito na API mesmo tendo Pro.
🤔 Tem cobrança automática todo mês?
NÃO. É pré-pago. Você coloca $5, usa, quando acabar para. Sem surpresa.
🤔 O crédito expira?
Os créditos avançados (para imagens) não expiram mas precisam de assinatura ativa. O saldo da API fica disponível enquanto a conta existir.
🤔 Posso usar cartão brasileiro?
Sim, cartão de crédito/débito com bandeira Visa ou Mastercard funciona. Se travar, tente cartão virtual do Nubank ou Inter.
🤔 Como sei quanto gastei?
Na plataforma, em "Billing", você vê o saldo atual e o histórico de uso em tempo real.
🤔 Posso usar nos meus projetos (Meu Chat, Laboratório)?
SIM! É exatamente para isso. Coloque a chave nas configurações do projeto e pronto.
